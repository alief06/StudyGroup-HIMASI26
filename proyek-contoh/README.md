# Halaman Profil Interaktif 👤

Proyek contoh untuk mata kuliah **Teknologi Web** – hasil akhir yang dibangun bersama selama sesi live coding.

## 🎯 Deskripsi

Website profil pribadi yang dibangun dari nol menggunakan **HTML5**, **CSS3**, dan **JavaScript murni** (tanpa library atau framework eksternal). Website ini mencakup:

- Halaman profil dengan avatar, nama, dan tagline
- Tombol **ganti tema** (gelap ↔ terang)
- Tombol **sapa** interaktif dengan pesan bergantian
- Section tentang diri, daftar skill, dan form kontak
- Desain responsif (tampil baik di HP maupun laptop)

## 🗂️ Struktur File

```
proyek-contoh/
├── index.html   ← Struktur halaman (HTML)
├── style.css    ← Tampilan & warna (CSS)
├── script.js    ← Interaktivitas (JavaScript)
└── README.md    ← Dokumentasi ini
```

## 🚀 Cara Menjalankan

Cukup **klik dua kali** pada file `index.html` — browser akan langsung membukanya. Tidak perlu server atau instalasi apapun.

## ✨ Fitur yang Diimplementasikan

| Fitur | Teknologi |
|---|---|
| Struktur semantik | HTML5 (`<header>`, `<main>`, `<section>`, `<footer>`) |
| Dark mode / light mode | CSS variabel + `classList.toggle` |
| Tombol sapa interaktif | JavaScript event listener + array |
| Form kontak | HTML form + JavaScript `preventDefault` |
| Desain responsif | CSS media query |
| Animasi hover | CSS `transition` + `transform` |

## 🛠️ Teknologi

- **HTML5** – Struktur dan konten
- **CSS3** – Gaya, variabel, animasi
- **Vanilla JavaScript** – Interaktivitas
- Tidak ada framework, tidak ada library eksternal ✅

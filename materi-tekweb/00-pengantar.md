# 00 – Pengantar: Sesi Teknologi Web

> **Mata Kuliah:** Teknologi Web  
> **Durasi Sesi:** 2 jam (120 menit)  
> **Peserta:** Mahasiswa pemula (belum pernah membuat website)

---

## 🎯 Tujuan Pembelajaran

Setelah sesi ini, peserta mampu:

1. Menjelaskan cara kerja web secara sederhana (client-server).
2. Memahami peran HTML, CSS, dan JavaScript dalam sebuah website.
3. Menulis kode HTML, CSS, dan JavaScript dasar dari nol.
4. Memublikasikan website ke internet menggunakan GitHub Pages.
5. Menggunakan DevTools browser untuk mengecek dan mendebug kode.

---

## 🗂️ Proyek yang Dibangun: Halaman Profil Interaktif

Sepanjang sesi ini kita akan membuat website profil yang memiliki:

- ✅ Nama, foto avatar, dan tagline
- ✅ Tombol **ganti tema** (gelap ↔ terang)
- ✅ Tombol **sapa** interaktif
- ✅ Section tentang diri & daftar skill
- ✅ Form kontak sederhana
- ✅ Dipublikasikan **gratis** di GitHub Pages
